# 🎵 BGM — Musik Latar

Taruh file musik latar di folder ini (`public/assets/audio/`).

File yang dikenali otomatis oleh website:

| Nama file   | Kegunaan                          |
|-------------|-----------------------------------|
| `bgm.mp3`   | Musik latar utama (loop, lembut)  |

Catatan:

- Format disarankan `.mp3` atau `.ogg`. Pilih lagu yang **ramai-menenangkan / cozy** dan punya **izin penggunaan yang jelas** (beberapa lisensi / milik sendiri).
- Musik **berikutnya otomatis saat pengguna menekan tombol "Masuk ke Birthday Town"** (ini tetap gesture pengguna, bukan autoplay saat halaman dibuka — jadi diizinkan browser).
- Setelah masuk, tombol `Musik` tetap bisa untuk menyalakan / mematikan kapan saja.
- Jika file `bgm.mp3` belum ada, tidak ada suara keluar dan tidak error.
- Jangan gunakan musik/aset game hasil ekstraksi sebagai kebutuhan wajib. Ini proyek fan-made.
